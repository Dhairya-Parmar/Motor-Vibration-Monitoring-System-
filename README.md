# Motor-Vibration-Monitoring-System-
A project based on ESP32 and ADXL345 Accelerometer 

An IoT based predictive maintenance solution using Esp32 Microcontroller and ADXL345 digital accelerometer to measure motor vibration dynamics in real time and push telemetry data to ThingSpeak via Wi-Fi. The project Also includes a small buzzer that goes off during abnormal vibrations.
